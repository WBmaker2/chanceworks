# ChanceWorks — 확률 실험실

ChanceWorks는 확률·통계를 직접 만져 보는 3D 확률 실험실입니다. 갈튼 보드, 두 주사위, 동전,
가중 돌림판, 기대값 실험을 통해 **실험 빈도와 이론 확률의 차이**, **큰 수의 법칙**, **독립 시행**,
**기대값**을 탐구합니다.

- 대상: 초등 5학년 ~ 고등 2학년
- 실행 환경: 최신 데스크톱·태블릿 브라우저
- 서버, 로그인, 데이터베이스, 분석 도구 없음
- 빌드 후 런타임 AI 호출·네트워크 호출 없음
- 모든 난수는 시드 기반 PRNG로 재현 가능

## 실험실

| 실험실    | 내용                                                                           |
| --------- | ------------------------------------------------------------------------------ |
| 갈튼 보드 | 5~12줄, 편향 0.1~0.9, 공 1~1000개, 관찰/이론 막대, 정규분포 근사, TV 수렴 미터 |
| 주사위    | 두 공정한 주사위의 합 분포, 36가지 결과표, 1000번 모의실험                     |
| 동전      | 1~1000번 던지기, 앞면 비율 그래프, 연속 앞면 탐지, 도박사의 오류 안내          |
| 돌림판    | 4~8칸, 칸별 가중치 편집, 관찰 빈도와 이론 가중치 비교                          |
| 기대값    | 상금·확률·참가비 편집, 기대값과 공정성 판정, 1000회 모의실험                   |
| 미션      | 6개 미션의 예측 → 실험 → 설명 흐름, 진행 상황 로컬 저장                        |
| 교사 모드 | 정답·해설 보기, 수업 시나리오, 진행 초기화, 인쇄용 워크시트                    |

## 시작하기

```bash
npm install
npm run dev
```

- 개발 서버: `http://localhost:5173`
- 프로덕션 빌드: `npm run build`
- 빌드 미리 보기: `npm run preview`

> Node.js 20 이상이 필요합니다. 이 프로젝트는 Node 24에서 검증했습니다.

## 검증

```bash
npm test          # Vitest 확률·통계 단위 테스트
npm run typecheck # TypeScript 검사
npm run lint      # ESLint
npm run test:e2e  # Playwright 브라우저 테스트 (빌드 후 preview 서버 사용)
```

Playwright는 처음 실행할 때 Chromium이 필요합니다.

```bash
npx playwright install chromium
```

## 설계 원칙

- **정직한 모델**: 3D 애니메이션은 결과를 꾸미는 시각 효과입니다. 결과는 시드로 미리 정해진
  모의실험이며 실제 사건을 예측하지 않습니다. 이 사실을 각 실험실 화면에 표시합니다.
- **재현 가능성**: 같은 시드와 설정은 같은 결과를 만듭니다. 화면에 시드가 표시되고 새 시드로
  다시 실행할 수 있습니다.
- **수학은 DOM 없이**: `src/prob/`의 모든 계산은 DOM과 분리되어 있어 단위 테스트가 가능합니다.
- **수렴은 경향**: 표본이 늘면 이론값에 가까워지는 경향이 있지만, 매 시행마다 TV가 반드시
  줄어든다고 주장하지 않습니다.
- **접근성**: 키보드 조작, 차트 데이터 표, 텍스트 요약, 색각 안전 팔레트,
  `prefers-reduced-motion`을 지원합니다.

## 프로젝트 구조

```text
src/
  app/          앱 셸, 라우팅, 상태
  prob/         시드 RNG, 이항분포, 주사위, 동전, 돌림판, 기대값, 수렴
  render/       Three.js 장면 (갈튼, 주사위, 동전, 돌림판)
  charts/       Canvas 2D 히스토그램, 비율 그래프, 수렴 미터
  features/     실험실 화면, 미션, 교사 모드
  data/         미션과 게임 프리셋 JSON
  storage/      localStorage 진행 저장
  tests/unit/   Vitest 테스트
e2e/            Playwright 테스트
```

## 로컬 저장과 개인정보

진행 상황은 브라우저 `localStorage`의 `chanceworks.progress.v1` 키에만 저장됩니다. 저장되는
항목은 완료한 미션, 예측·설명 답안, 마지막 실험실, 표시 설정입니다. 개별 실험 결과나 개인
정보는 저장하지 않습니다. 교사 모드에서 언제든 초기화할 수 있습니다.

## 라이선스

교육용 프로젝트입니다. 외부 텍스처나 모델 파일 없이 절차적 재질과 시스템 글꼴만 사용합니다.
